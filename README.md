# 🎓 CampusScope AI

> **AI-Powered Smart Campus Complaint Management System**

A modern full-stack platform that transforms the traditional complaint process into an intelligent, transparent, and role-based campus management system. CampusScope AI enables students to report issues with evidence while providing administrators with AI-assisted prioritization, analytics, and real-time resolution tracking.

---

## 🌐 Live Demo

**🔗 Website:** https://campusai-mdyjycqy.manus.space/

## ✨ Key Features

### 👨‍🎓 Student Portal

* Secure student authentication
* Submit complaints with image evidence
* AI-assisted complaint categorization
* Real-time complaint status tracking
* Push notifications for updates
* Feedback after issue resolution
* Profile & hostel information management

### 🛠️ Admin Portal

* Role-based administrator login
* Interactive complaint dashboard
* AI priority scoring (Low → Critical)
* Assign complaints to faculty members
* Complaint heatmap & analytics
* Employee management system
* Resolution history and reports

## 📊 System Workflow

1. Student logs into the portal
2. Complaint submitted with optional image evidence
3. AI analyzes severity & priority
4. Admin reviews the complaint
5. Faculty member gets assigned
6. Issue resolved and student notified
7. Student provides feedback
