# CampusScope AI

An AI-powered campus complaint management platform with separate **Student** and **Admin** portals.

## Live Demo

**Website:** https://campusai-mdyjycqy.manus.space/

## Features

* Role-based login (Student & Admin)
* AI-powered complaint prioritization
* Complaint submission with image evidence
* Admin dashboard with complaint assignment
* Faculty/employee management
* Real-time notifications
* Analytics and heatmap visualization
* Feedback system after complaint resolution

## Tech Stack

* React + TypeScript
* Vite
* Express.js
* tRPC
* Drizzle ORM
* MySQL
* Tailwind CSS
* OpenAI (AI prioritization)
